# 三站斜距三角定位

已知三个基准站的精确坐标，以及各站到流动站的斜距，求流动站位置。实现见 `src/triangulation.cpp`，入口是 `sbl::triangulation::solve`。

坐标为局部笛卡尔，单位米，Z 向上。斜距单位也是米。

## 几何

流动站 P 同时落在三个球面上：

```text
|P - A| = ra
|P - B| = rb
|P - C| = rc
```

A、B、C 不共线时，这三个球面一般有 0、1 或 2 个交点。两个交点关于 A、B、C 所在平面镜像。流动站正好在该平面上时，两个交点重合，只有一个解。

## 封闭解

先把坐标系变到三站平面上，求出局部坐标，再变回原坐标。不做迭代。

1. 平移，使 A 为原点。
2. 取单位向量 `ex` 沿 A→B。记基线长度 `d = |B - A|`，则 B 的局部坐标是 `(d, 0, 0)`。
3. 取单位向量 `ez` 沿 `(B - A) × (C - A)`，再取 `ey = ez × ex`。C 落在局部 xy 平面，坐标记为 `(i, j, 0)`，其中 `j > 0`。
4. 由三条斜距求 P 的局部坐标：

```text
x  = (ra² - rb² + d²) / (2d)
y  = (ra² - rc² + i² + j² - 2·i·x) / (2j)
z² = ra² - x² - y²
```

5. 变回原坐标。`z² > 0` 时有两个点：

```text
P+ = A + x·ex + y·ey + z·ez
P- = A + x·ex + y·ey - z·ez
```

`z = sqrt(z²)`。`P+` 与 `(B-A)×(C-A)` 同侧。

`z²` 不小于 `-1e-8` 且不超过 `1e-8`（单位 m²）时，视为落在三站平面上，只取 `z = 0` 的那一个点。`z² < -1e-8` 时三球没有实交点。

## 用高程得到唯一解

两个镜像点算出来之后，比较它们在原坐标系里的 z。

| `height_select` | 保留 |
|---|---|
| `HeightSelect::Higher`（默认） | z 较高的点 |
| `HeightSelect::Lower` | z 较低的点 |

高程差大于 `1e-6` m 时只返回选中的一个点。差不超过 `1e-6` m 时，两点高程相同，标志无法区分，两个点都返回。三站平面接近竖直时会出现这种情况。

落在三站平面上时本来就只有一个点，标志不再做选择。

## 无法求解的输入

以下情况返回 `InvalidInput`：

- 任一斜距不是正的有限数，或任一坐标不是有限数
- 任意两站距离小于 `1e-6` m
- 三站共线，定不出平面。判据是 C 到直线 AB 的距离小于 `1e-6` m

三球没有实交点时返回 `NoSolution`。

## 定位误差评估

配置给出 `slant_range_error` 和 `base_error_x`、`base_error_y`、`base_error_z`，单位米。同一组数用两次：极限法把它当作不许超出的误差界限，协方差法把它当作 1σ。斜距误差对每条参与解算的斜距相同；基站某一坐标分量的误差对该分量在每个参与解算的基站上相同。

### 最大误差

最大误差是端点组合的全宽，不是标准差。

1. 先用配置真值解出标称位置。
2. 每个非零误差量只取两个端点：真值加误差，或真值减误差。误差为 0 的量保持真值，不增加组合。
3. 三站定位的组合量是 A、B、C 各自的 x、y、z，以及三条斜距。双站定位的组合量是 A、B 各自的 x、y、z，以及两条斜距。已知高度不作为误差量。
4. 每个量的正负端点互相独立，全部端点组成 `2^n` 组输入。
5. 每一组都用与标称解相同的 `height_select` 或 `side_select` 再解一次。无法解出的组合丢掉。
6. 最大误差是成功解里该坐标最大值与最小值之差的绝对值：

```text
max_error_x = |x_max - x_min|
max_error_y = |y_max - y_min|
max_error_z = |z_max - z_min|
```

三站给出 x、y、z。双站加已知高度只给出 x、y。某一组端点如果跨到另一侧交点，对应的最大误差会明显变大。

### 协方差不确定度

在标称位置处把斜距线性化。目标移动 \(\delta p\) 时，到基站 \(i\) 的斜距大约变化 \(\mathbf{u}_i\cdot\delta p\)，\(\mathbf{u}_i\) 是从该基站指向标称位置的单位矢量。信息矩阵是

```text
N = Σ (u_i u_i^T / σ_i^2)
P = N^{-1}
sigma_x = sqrt(P_xx)
sigma_y = sqrt(P_yy)
sigma_z = sqrt(P_zz)
```

第 \(i\) 条斜距的方差是测距 1σ 的平方，再加上站址 1σ 沿视线的投影：

```text
σ_i^2 = slant_range_error^2
      + (u_x base_error_x)^2
      + (u_y base_error_y)^2
      + (u_z base_error_z)^2
```

三站定位的 \(\mathbf{u}\) 用三个分量，估计 x、y、z。双站加已知高度只把 \(u_x、u_y\) 放进信息矩阵，不估计 z，因此不输出 `sigma_z`。视线共线或法方程不可逆时，协方差记为不可用。`sigma_*` 是对应坐标误差的 1 倍标准差。
